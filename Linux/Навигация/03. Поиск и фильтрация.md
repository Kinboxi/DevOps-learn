# Глава 4. Поиск и фильтрация

> [!info] Зачем это знать
> Искать файлы и фильтровать текст — то чем ты занимаешься постоянно. Найти лог, ошибку, конфиг, посчитать строки — всё это grep, find, wc.

---

## Поиск внутри файлов

### grep "текст" file.txt
```
> найти строки содержащие текст в файле
```

### grep -r "текст" /path/
```
> искать рекурсивно во всех файлах директории
```

### grep -i "текст" file.txt
```
> без учёта регистра
```

### grep -n "текст" file.txt
```
> показать номера строк
```

### grep -v "текст" file.txt
```
> показать строки НЕ содержащие текст
```

---

## Поиск файлов

### find /path -name "file.txt"
```
> найти файл по имени
```

### find . -type f
```
> только файлы
```

### find . -type d
```
> только папки
```

### find / -name "*.log"
```
> найти все лог файлы во всей системе
```

---

## Сортировка и уникальность

### sort file
```
> отсортировать строки по алфавиту
```

### sort -r file
```
> в обратном порядке
```

### sort -n file
```
> сортировать по числам
```

### uniq file
```
> убрать дубликаты (только если строки уже отсортированы)
```

### uniq -c file
```
> посчитать повторения каждой строки
```

---

## Подсчёт строк

### wc file
```
> строки, слова, символы
```

### wc -l file
```
> только строки
```

### wc -w file
```
> только слова
```

---

## Обрезка колонок

### cut -d: -f1 /etc/passwd
```
> вырезать первую колонку (разделитель `:`)
```

### cut -d, -f2 file.csv
```
> вторую колонку из CSV
```

---

## Просмотр файлов

### head file
```
> первые 10 строк
```

### head -n 5 file
```
> первые 5 строк
```

### tail file
```
> последние 10 строк
```

### tail -n 5 file
```
> последние 5 строк
```

### tail -f /var/log/syslog
```
> следить за файлом в реальном времени
```

### less file
```
> открыть файл с прокруткой (q — выйти, / — поиск)
```

---

## Примеры

### grep "error" log.txt
```
> найти все ошибки в логе
```

### grep -r "root" /etc/
```
> найти где в конфигах упоминается root
```

### find . -name "*.log"
```
> найти все лог файлы в текущей папке
```

### find / -name "passwd"
```
> найти где лежит файл passwd
```

### sort names.txt | uniq -c
```
> отсортировать и посчитать повторения имён
```

### wc -l /var/log/syslog
```
> сколько строк в логе
```

### cut -d: -f1 /etc/passwd
```
> список всех пользователей в системе
```

### tail -f /var/log/syslog
```
> смотреть новые записи в логе в реальном времени
```
