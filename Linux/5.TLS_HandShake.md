# TLS/SSL HANDSHAKE 


## Мета тлс хендшейку полягає в тому щоб перевірити автентичність сервера та створити спільний ключ сесії для шифрування 

1. Client Hello - Брацзер надсилає версію TLS, список підтримки шифрів та випадкове число (Server Random).
2. Server Hello - Сервер обирає шифр, надсилає свій Server Random та SSl сертифікат.
3. Key exchange - (обмін ключами) Клієнт перевіряє сертифікат через центр Сертифікації (CA) 
   обидві сторони генерують секрет (Pre-Master Secret) і створюють з нього однаковий симетричний ключ.
4.   Finised    - обидві сторони надсилають зашифровані текстові повідомлення.

   **Асиметричне шифрування — тільки під час Handshake (для безпечного обміну ключами).**
   **Симетричне шифрування — після Handshake (для швидкої передачі даних).**
