# 4. Пользователи и группы

> [!info] Зачем это знать
> Linux — многопользовательская система. Управление пользователями, группами и правами — база для любого администратора и DevOps инженера.

---

## Важные файлы

### /etc/passwd
Хранит информацию о всех пользователях системы.

```
username:x:UID:GID:comment:home:shell
```

Пример:
```
resh:x:1000:1000:Resh:/home/resh:/bin/bash
```

- **username** — имя пользователя
- **x** — пароль хранится в /etc/shadow
- **UID** — id пользователя
- **GID** — id основной группы
- **comment** — полное имя или описание
- **home** — домашняя директория
- **shell** — оболочка пользователя

### /etc/shadow
Хранит зашифрованные пароли. Доступен только root.

```
username:hash:lastchange:min:max:warn:inactive:expire
```

- **hash** — зашифрованный пароль
- **lastchange** — когда последний раз менялся пароль
- **min/max** — минимум/максимум дней между сменами
- **warn** — за сколько дней предупреждать об истечении
- **expire** — когда истекает аккаунт

### /etc/group
Хранит все группы системы.

```
groupname:x:GID:members
```

Пример:
```
sudo:x:27:resh
docker:x:999:resh,user2
```

### /etc/default/useradd
Дефолтные настройки при создании пользователя.

```bash
useradd -D        # посмотреть дефолтные настройки
```

## Типы групп

- **Primary group** — одна, обязательная. Файлы созданные пользователем принадлежат этой группе.
- **Secondary group** — дополнительные. Дают доступ к ресурсам группы.

---

## RUID и EUID

**RUID** — реальный ID. Кем ты вошёл в систему. Не меняется.

**EUID** — эффективный ID. От чьего имени сейчас выполняются команды.

> [!tip] Аналогия
> RUID — твой настоящий паспорт. EUID — маска которую ты надел. `whoami` говорит какая маска, `who am i` говорит кто за маской.

## Управление пользователями

### useradd
```bash
useradd username                        # создать пользователя
useradd -m username                     # создать с домашней директорией
useradd -m -s /bin/bash username        # указать оболочку
useradd -m -s /bin/bash -g group user   # указать основную группу
```

### passwd
```bash
passwd username       # установить или сменить пароль
```

### usermod
```bash
usermod -l newname username     # переименовать пользователя
usermod -d /new/home username   # сменить домашнюю директорию
usermod -s /bin/zsh username    # сменить оболочку
usermod -g newgroup username    # сменить основную группу
usermod -aG sudo username       # добавить в дополнительную группу
```

> [!tip] Важно
> `-aG` — append to Group. Без `-a` ты заменишь все группы пользователя.

### userdel
```bash
userdel username      # удалить пользователя (папка остаётся)
userdel -r username   # удалить пользователя и домашнюю папку
```

> [!info] Заметка
> `userdel -r` не удаляет группы. Группы удаляешь отдельно через `groupdel`.

### chage — политика паролей
```bash
chage -l username       # посмотреть настройки пользователя
chage -M 90 username    # пароль истекает через 90 дней
chage -m 7 username     # минимум 7 дней между сменами
chage -W 14 username    # предупреждать за 14 дней
chage -d 0 username     # сменить пароль при следующем входе
chage -E 2026-12-31 username  # аккаунт истекает в эту дату
```

## Управление группами

### groupadd
```bash
groupadd devops           # создать группу
groupadd -g 1500 devops   # создать с конкретным GID
```

### groupmod
```bash
groupmod -n newname oldname   # переименовать группу
```

### groupdel
```bash
groupdel groupname    # удалить группу
```

> [!tip] Важно
> Нельзя удалить группу если она является основной для какого-то пользователя. Сначала смени основную группу пользователя, потом удаляй.

## Мониторинг пользователей

### whoami
```bash
whoami
```
> показывает EUID — кем ты сейчас действуешь

### who am i
```bash
who am i
```
> показывает RUID — кем ты вошёл изначально

### who
```bash
who           # кто сейчас в системе
who -H        # с заголовком (IP + время входа)
who -a        # расширенная информация
```

### id
```bash
id
id username
```
> показывает UID, GID и все группы пользователя

### w
```bash
w
```
> кто в системе, что делает, нагрузка на систему

### uptime
```bash
uptime
```
> время работы системы и load average за 1, 5 и 15 минут

### last
```bash
last                  # история всех входов и выходов
last username         # фильтр по пользователю
last reboot           # история перезагрузок
```

## Вопросы на собеседовании

**"Чем /etc/shadow отличается от /etc/passwd?"**
→ passwd читаем всеми, shadow только root. passwd хранит информацию о пользователе, shadow — зашифрованный пароль.

**"Что такое primary и secondary group?"**
→ Primary — одна, обязательная. Secondary — дополнительные для доступа к ресурсам.

**"Чем whoami отличается от who am i?"**
→ whoami — эффективный пользователь (EUID), who am i — реальный (RUID).

**"Как добавить пользователя в группу не убирая из других?"**
→ `usermod -aG groupname username` — флаг `-a` означает append.

**"Почему нельзя удалить группу?"**
→ Скорее всего она является основной для какого-то пользователя. Сначала смени группу пользователю, потом удаляй.
