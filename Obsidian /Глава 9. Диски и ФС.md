```
> показує номер inode файлу
```

### stat
```

## Файлові системи

Спосіб організації даних на диску.

- **ext4** — стандарт для Linux, стабільна, перевірена
- **xfs** — краще для великих файлів і серверів
- **btrfs** — сучасна, підтримує snapshots і compression
- **tmpfs** — існує тільки в RAM, зникає після перезавантаження

## df + du

**df** — показує скільки місця зайнято на розділах

### df -h
```

> розмір у людиночитаємому форматі (GB, MB)
```

**du** — показує скільки важить конкретна папка або файл

### du -sh /var/log
```
> розмір папки /var/log
```

### du -sh /* 2>/dev/null
```
> розмір всіх папок в кореневій директорії
```

> [!tip] Різниця
> df — загальна картина диска. du — знайти де саме з'їдається місце.

## /etc/fstab

Файл який визначає що монтується автоматично при завантаженні системи.

Формат рядка:
```
UUID=xxxx  /mnt/data  ext4  defaults  0  2
```

- **UUID** — унікальний ідентифікатор розділу
- **/mnt/data** — точка монтування
- **ext4** — тип файлової системи
- **defaults** — стандартні опції
- **0** — чи включати в dump бекап
- **2** — порядок перевірки fsck при завантаженні

### blkid
```

> показати UUID всіх розділів
```

## RAID

Об'єднання кількох дисків для надійності або швидкості.

- **RAID 0** — дані розбиваються між дисками, швидко але якщо один диск помер — всі дані втрачено
- **RAID 1** — дзеркало, дані дублюються на два диски, надійно
- **RAID 5** — мінімум 3 диски, баланс між швидкістю і надійністю, витримує смерть одного диска
- **RAID 6** — як RAID 5 але витримує смерть двох дисків
- **RAID 10** — RAID 1 + RAID 0, швидко і надійно, але потрібно мінімум 4 диски

### mdadm
```
> інструмент для управління програмним RAID в Linux
```

## LVM

**Logical Volume Manager** — гнучке управління дисковим простором. Дозволяє змінювати розмір розділів без перезавантаження.

Три рівні:
- **PV** (Physical Volume) — фізичний диск або розділ
- **VG** (Volume Group) — пул з одного або кількох PV
- **LV** (Logical Volume) — віртуальний розділ з VG, з яким і працюєш

### pvcreate /dev/sdb
```

> зробити диск фізичним томом
```

### vgcreate my_vg /dev/sdb
```
> створити групу томів
```

### lvcreate -L 20G -n my_lv my_vg
```
> створити логічний том розміром 20GB
```

### lvextend -L +10G /dev/my_vg/my_lv
```
> розширити логічний том на 10GB
```

### resize2fs /dev/my_vg/my_lv
```
> розширити файлову систему після lvextend
```
