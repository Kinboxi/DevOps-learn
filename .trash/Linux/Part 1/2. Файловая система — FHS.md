# 2. Файловая система — FHS

> [!info] Зачем это знать
> Без понимания структуры файловой системы ты не поймёшь где лежат конфиги, логи, команды и устройства. Это база для администрирования и DevOps.

---

## Что такое файловая система

В Linux всё является файлом — команды, устройства, процессы, конфиги. Всё организовано в одно дерево начиная с корня `/`.

> [!tip] Аналогия
> Файловая система — это дерево. Корень `/` — это ствол. Все директории — ветки. Файлы — листья.

---

## FHS — Filesystem Hierarchy Standard

Стандарт который определяет где что должно лежать в Linux. Все дистрибутивы следуют этому стандарту.

---

## Основные директории

### /
Корень файловой системы. Всё начинается отсюда.

### /bin
Основные команды системы — `ls`, `cp`, `mv`, `cat`, `bash`.
Доступны всем пользователям.

> [!info] Заметка
> В современных системах `/bin` — это симлинк на `/usr/bin`. Раньше были разделены.

### /etc
Конфигурационные файлы системы и приложений.
Nginx, SSH, systemd, сеть — всё настраивается здесь.

```
/etc/nginx/nginx.conf
/etc/ssh/sshd_config
/etc/fstab
```

### /home
Домашние директории пользователей.

```
/home/resh
/home/user2
```

### /root
Домашняя директория пользователя root. Отдельно от /home.

### /var
Изменяемые данные — логи, базы данных, кэш. Накапливаются со временем.

```
/var/log/syslog
/var/log/nginx/
```

### /tmp
Временные файлы. Очищаются при перезагрузке системы.

### /usr
Программы и библиотеки установленные пользователем.

```
/usr/bin    — команды пользователя
/usr/lib    — библиотеки
/usr/share  — общие данные
```

### /bin vs /usr/bin
- `/bin` — критически важные команды нужные при загрузке
- `/usr/bin` — остальные команды пользователя
- В современных системах `/bin` = симлинк на `/usr/bin`

### /dev
Устройства системы представлены как файлы.

```
/dev/sda    — жёсткий диск
/dev/sda1   — первый раздел
/dev/null   — чёрная дыра, всё что туда пишешь исчезает
```

### /proc
Виртуальная файловая система. Создаётся ядром в памяти при загрузке.
Реальных файлов на диске нет. Содержит информацию о процессах и ядре.

```
/proc/1       — информация о процессе с PID 1
/proc/cpuinfo — информация о процессоре
/proc/meminfo — информация о памяти
```

### /mnt
Точка для ручного монтирования устройств.

### /media
Точка для автоматического монтирования — флешки, CD, внешние диски.

> [!tip] Запомни
> **/media** = автомат (система монтирует сама)
> **/mnt** = вручную (ты монтируешь сам)

### /opt
Дополнительное программное обеспечение установленное вручную.

### /lib
Библиотеки необходимые для команд из /bin и /sbin.

---

## Вопросы на собеседовании

**"Где хранятся конфиги?"** → `/etc`

**"Где смотреть логи?"** → `/var/log`

**"Чем /proc отличается от обычных директорий?"** → Виртуальная файловая система, существует только в памяти, создаётся ядром.

**"Чем /bin отличается от /usr/bin?"** → Исторически /bin для критических команд при загрузке, /usr/bin для остальных. В современных системах это симлинк.

**"Что такое /dev/null?"** → Виртуальное устройство — всё что туда пишешь исчезает. Используется для подавления вывода.
