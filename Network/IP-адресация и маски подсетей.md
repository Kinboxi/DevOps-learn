# 2. IP-адресация и маски подсетей

> [!info] Зачем это знать
> Без этого не настроишь nginx, не поймёшь почему не работает сайт, не ответишь на половину собеседований.

---

## Что такое IP-адрес простыми словами

**IP-адрес** — это адрес компьютера в сети. Как номер дома на улице.

Пример:
```
192.168.1.10
```

Если ты хочешь открыть сайт — браузер узнаёт IP-адрес этого сайта и обращается к нему.

> [!tip] Аналогия
> Твой домашний адрес: **ул. Ленина, дом 5, кв 10**  
> IP-адрес: **192.168.1.10**

---

## Что такое порт

IP указывает на **компьютер**, а **порт** — на программу внутри этого компьютера.

```
192.168.1.10:80
│── компьютер ──│││
                 └── программа (веб-сервер)
```

Стандартные порты (их надо знать):
- **22** — SSH (подключение к серверу)
- **80** — HTTP (сайт без шифрования)
- **443** — HTTPS (сайт с шифрованием)
- **3306** — MySQL
- **5432** — PostgreSQL

## Что такое маска подсети

Маска показывает, какие компьютеры **рядом** (в одной сети), а какие **далеко** (в другой сети).

Маска **255.255.255.0** (она же `/24`) — самая популярная.

Она означает: компьютеры, у которых **первые 3 цифры совпадают** — они рядом.

Пример:

```
Компьютер А: 192.168.1.10  с маской 255.255.255.0
Компьютер Б: 192.168.1.50  с маской 255.255.255.0
```

У них совпадают **192.168.1** — значит они в одной сети, могут общаться напрямую.

```
Компьютер А: 192.168.1.10
Компьютер В: 10.0.0.5
```

Первые 3 цифры разные — **в разных сетях**. Нужен маршрутизатор (роутер).

> [!tip] Как быстро понять
> Маска **255.255.255.0** = смотри только на **первые 3 числа** IP-адреса.  
> Если они совпадают — вы в одной локальной сети.

## Как вычислить вручную (главный навык)

Дано:
```
IP:     192.168.1.42
Маска:  255.255.255.0 (/24)
```

### 1. Адрес сети
Это "название" всей твоей сети. Берёшь IP, где маска **255** — оставляешь, где **0** — ставишь **0**.

```
192.168.1.42  +  маска 255.255.255.0
│   │   │                 │   │   │
192.168.1  →  а 0 заменяем на 0
```
**Адрес сети:** `192.168.1.0`

### 2. Broadcast-адрес
То же самое, но где в маске **0** — ставишь **255**.

```
192.168.1.42  +  маска 255.255.255.0
│   │   │
192.168.1.255
```
**Broadcast:** `192.168.1.255`

### 3. Диапазон адресов
Всё что между сетью и broadcast.

```
Сеть:   192.168.1.0
Broad:  192.168.1.255
─────────────────────
Можно использовать: 192.168.1.1 — 192.168.1.254
```

### 4. Шлюз (роутер)
Это выход в интернет. Обычно **первый** адрес из диапазона.

```
Шлюз: 192.168.1.1
```

## Другие маски (просто чтобы знать)

| Маска | /? | Сколько адресов | Где используется |
|-------|----|-----------------|------------------|
| 255.255.255.0 | /24 | 254 | Дом, маленький офис |
| 255.255.0.0 | /16 | 65 534 | Крупный офис |
| 255.0.0.0 | /8 | 16 млн | Огромные сети |
| 255.255.255.240 | /28 | 14 | Облачные подсети |
| 255.255.255.252 | /30 | 2 | Между маршрутизаторами |

> [!warning] Почему на 2 меньше?
> Первый адрес — это **название сети**, последний — **broadcast** (для всех сразу). Их нельзя давать компьютерам.

Пример для маски **255.255.255.240** (`/28`):

```
IP:        192.168.1.40
Маска:     255.255.255.240

Сеть:      192.168.1.32          (октет 40 → 32)
Broadcast: 192.168.1.47          (32 + 16 - 1)
Диапазон:  192.168.1.33 — 192.168.1.46
```

## Private и Public IP

**Private IP** — только внутри твоей сети. В интернете так не обращаются.

```
192.168.x.x     — дома (роутер выдаёт)
10.x.x.x        — на работе, в облаках
172.16-31.x.x   — реже
```

**Public IP** — настоящий адрес в интернете. Его даёт провайдер.

У тебя дома:
- Компьютеры получают private IP (192.168.1.x)
- Роутер имеет public IP (выход в интернет)
- Роутер сам решает, кому из устройств отдать ответ (это **NAT**)

---

## Loopback (127.0.0.1)

`127.0.0.1` — это ты сам. Если что-то запущено на твоём компьютере — оно доступно по этому адресу.

```bash
ping 127.0.0.1    # проверка, что сетевой стек работает
curl 127.0.0.1    # запрос к серверу на своём же компьютере
```

## Что надо уметь руками

### 1. Посмотреть свой IP в Linux
```bash
ip addr
```

Ищешь строку `inet 192.168.1.x/24`. Видишь свой IP и маску.

### 2. Узнать шлюз
```bash
ip route
```

Ищешь `default via 192.168.1.1` — это твой роутер.

### 3. Проверить, работает ли сеть
```bash
ping 8.8.8.8         # пингует Google — значит есть интернет
ping 192.168.1.1     # пингует роутер — значит локальная сеть работает
```

Если `ping 8.8.8.8` не идёт, а `ping 192.168.1.1` идёт — проблема выше роутера (у провайдера).

### 4. Проверить, работает ли конкретный порт
```bash
curl -I http://192.168.1.100:8080
# или
telnet 192.168.1.100 8080
```

## Типичные вопросы на собесе

> [!question] "Что такое IP-адрес?"
> Адрес компьютера в сети. Как номер дома.

> [!question] "Что такое маска 255.255.255.0?"
> Показывает, что первые 3 числа IP-адреса — это сеть, последнее — конкретный компьютер в этой сети.

> [!question] "Какой адрес сети у 192.168.1.42/24?"
> 192.168.1.0.

> [!question] "Сколько адресов можно использовать в /24?"
> 254 (256 всего, минус адрес сети и broadcast).

> [!question] "Чем отличается private IP от public?"
> Private (192.168.x.x, 10.x.x.x) — только внутри локальной сети. Public — настоящий адрес в интернете.

> [!question] "Что такое NAT?"
> Когда несколько компьютеров с private IP выходят в интернет через один public IP роутера.

> [!question] "Что такое 127.0.0.1?"
> Адрес твоего же компьютера (localhost).

> [!question] "А если маска 255.255.0.0?"
> Тогда совпадают только первые 2 числа. Пример: 10.0.1.5 и 10.0.200.5 — в одной сети (совпадает 10.0).

---

> [!summary] Главное
> - IP — адрес компа, порт — адрес программы внутри компа
> - Маска `/24` (255.255.255.0) — смотри первые 3 цифры
> - Адрес сети: где в маске 0 → ставим 0
> - Broadcast: где в маске 0 → ставим 255
> - Диапазон: между сетью и broadcast
> - Шлюз — выход в интернет (обычно первый адрес)
> - private: 192.168.x.x, 10.x.x.x — для локальных сетей
> - Команды: `ip addr`, `ip route`, `ping`
