
# Квадратне рівняння — це рівняння вигляду:
$$\Large ax^2 + bx + c = 0$$

* **a** — число перед $x^2$ (якщо там порожньо — це 1)
* **b** — число перед звичайним $x$ (знак забираємо разом із числом)
* **c** — вільне число наприкінці

---

## 1. Неповні рівняння (без дискримінанта)

### Тип А: Немає звичайного ікса ($b = 0$)
$$\Large x^2 - c = 0$$
* **Що робити:** Перенести число праворуч і взяти корінь.
* **Приклад:** $$\Large x^2 - 16 = 0$$
  $$\Large x^2 = 16$$
  $$\Large x = \pm 4$$

### Тип Б: Немає чистого числа ($c = 0$)
$$\Large x^2 \pm bx = 0$$
* **Що робити:** Винести $x$ за дужки. Один із коренів завжди нуль.
* **Приклад:**
  $$x^2 - 5x = 0$$
  $$x(x - 5) = 0$$
  $$\Large x_1 = 0, \quad x_2 = 5$$

---

## 2. Повні рівняння (через Дискримінант)

### Крок 1: Рахуємо Дискримінант
$$\Large D = b^2 - 4ac$$
* **D > 0** — 2 різних корені
* **D = 0** — 1 корінь
* **D < 0** — розв'язків немає

### Крок 2: Знаходимо корені
$$\Large x_1 = \frac{-b + \sqrt{D}}{2a}$$

$$\Large x_2 = \frac{-b - \sqrt{D}}{2a}$$

*Примітка: Якщо $b$ від'ємне (наприклад, $-6$), то у формулу йде $+6$.*

---

## 3. Теорема Вієта (швидкий підбір)
Працює, якщо перед $x^2$ немає числа ($a = 1$).

$$\Large x_1 \cdot x_2 = c$$
$$\Large x_1 + x_2 = -b$$

* **Приклад:** $x^2 - 7x + 12 = 0$
  Добуток = 12, сума = 7.
  $$\Large x_1 = 3, \quad x_2 = 4$$

---

## 4. Пастки на тестах

### Біквадратні (Заміна)
$$\Large ax^4 + bx^2 + c = 0$$
Заміняємо $x^2 = t$. Розв'язуємо звичайне рівняння $at^2 + bt + c = 0$, знаходимо $t$, а потім повертаємося до $x^2 = t$.

### ОДЗ (Дріб)
$$\Large \frac{ax^2 + bx + c}{x - k} = 0$$
Знаменник не дорівнює нулю: $x \neq k$. Якщо цей $k$ вийде серед коренів чисельника через Дискримінант, його треба викинути з відповіді.
